# Lives 0.1.8

正式版，适用于 Apple Silicon Mac，最低系统要求为 macOS 13。

## 本次更新

- 修复“保存到照片”提示前往系统设置、却找不到 Lives 的问题。补齐主程序和照片辅助程序的 Hardened Runtime 照片权限声明，仍仅请求添加照片，不读取现有图库。
- 区分签名配置异常、系统限制和用户拒绝；配置异常时不再引导用户去设置中寻找不存在的条目，并提供导出到文件夹的替代路径。
- DMG 安装窗口调整为 640 × 440，增加拖拽箭头、安装说明及“安装后从应用程序打开”的提醒。
- 修复辅助程序动态库在打包复制后签名失效的问题，增加主程序、辅助程序和照片权限的发布检查。
- 修正 beta 与正式版的版本比较，支持从预发布版升级到对应正式版。

## 安装

1. 下载本页的 `Lives_0.1.8_aarch64.dmg`，核对 `.sha256` 文件。
2. 退出旧版，将 Lives 拖入“应用程序”文件夹。
3. 从“应用程序”打开 Lives，不要直接运行 DMG 内的副本；首次保存到“照片”时允许“仅添加照片”。

本版使用 Developer ID 签名，并完成 Apple 公证及票据钉入。本版通过正式版自动更新、官网和稳定下载镜像分发。

## 验证与已知限制

- 已在 macOS 27 开发预览版上验证真实照片授权弹窗、授权成功返回和授权记录创建，并检查安装镜像布局与签名。
- 本次未重新完成 macOS 13/14、所有导出模板、iCloud 与 iPhone 的完整回归；相关素材集成测试缺少输入时明确跳过。
- 升级后建议先用非重要素材验证。反馈时附上系统版本和复现步骤，请勿公开私人照片、视频或未脱敏日志。
