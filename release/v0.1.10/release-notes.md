# Lives 0.1.10

正式版，适用于 Apple Silicon Mac，最低系统要求为 macOS 13。

## 本次更新

- 修复照片权限误点“不允许”后无法恢复的问题：macOS 不会在“隐私与安全性 → 照片”面板中列出被拒绝的“仅添加照片”应用，导致一旦拒绝就再也无法保存。现在导出界面提供“重新授权并保存”，自动重置本应用的授权记录并重新弹出系统授权框，恢复期间显示明确的进度与预期时长（通常更快，最长约 3 分钟）。
- 新增“复制修复命令”兜底：自动化恢复不可用或系统未弹出授权框时，一键复制官方 tccutil 命令，在“终端”粘贴执行即可恢复；恢复全过程记录在 `~/Library/Logs/Lives/photo-reset.log`，便于反馈与排查。
- 连续多次在系统弹窗中拒绝授权后，恢复界面优先推荐“改存到文件夹”，并保留重新授权入口。
- 画布支持自定义比例：拖动画布四角的比例手柄，即可任意调节宽高比，方向切换自动换算。
- 文件夹素材库支持一键同步：重新扫描文件夹自动加入新视频、移除已删除素材，启动时也会静默同步最新内容。
- 包含 0.1.9 的封面方向修复与多画格独立关键帧。

## 安装

1. 下载本页的 `Lives_0.1.10_aarch64.dmg`，核对 `.sha256` 文件。
2. 退出旧版，将 Lives 拖入“应用程序”文件夹。
3. 从“应用程序”打开 Lives，不要直接运行 DMG 内的副本；首次保存到“照片”时允许“仅添加照片”。

本版使用 Developer ID 签名，并完成 Apple 公证及票据钉入。本版通过正式版自动更新、官网和稳定下载镜像分发。

## 验证与已知限制

- 已验证照片授权自动恢复链路与诊断日志、自定义比例、文件夹同步，自动化测试（Swift 全套与前端用例）通过，安装包签名、公证与 Gatekeeper 评估通过。
- 照片授权自动恢复依赖 macOS 对“仅添加照片”授权记录的重置行为，已在 macOS 27 开发预览版实测；若自动恢复未成功，导出界面会始终提供“复制修复命令”与“改存到文件夹”两条出路，不会无声卡死。
- 本次未重新完成 macOS 13/14、所有导出模板、iCloud 与 iPhone 的完整回归；相关素材集成测试缺少输入时明确跳过。
- 升级后建议先用非重要素材验证。反馈时附上系统版本、`photo-reset.log` 日志和复现步骤，请勿公开私人照片、视频或未脱敏日志。
