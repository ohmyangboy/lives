# Lives 0.1.11

正式版，适用于 Apple Silicon Mac，最低系统要求为 macOS 13。

## 本次更新
- 2026-08-30 替换稳定下载产物为支持自有源优先检测、GitHub 备用、下载取消与完整安装校验的公证构建；版本号仍为 0.1.11。

- 反馈与“关于”中的设备信息改为真实系统数据：此前显示的是 WebView 内置的占位信息（“MacIntel”、Intel Mac 的 User Agent），现在通过本机接口采集操作系统版本、芯片型号、设备型号、内存、处理器核心数、主显示器分辨率与缩放、系统语言区域。
- 应用内更新安装并重启后，首次启动会弹出“已更新”提示：如果新版本遇到任何问题或有功能建议，可一键打开预填好的反馈邮件联系开发者；每次更新只提示一次。
- 修正部分设备上照片权限恢复链路的边界情况：授权状态统一由全新辅助进程读取，重置动作串行化并支持中途取消，自动化恢复失败时始终提供“复制修复命令”与“改存到文件夹”两条出路。
- 包含 0.1.10 的照片权限拒绝后应用内恢复、画布自定义比例拖拽与文件夹素材库同步。

## 安装

1. 下载本页的 `Lives_0.1.11_aarch64.dmg`，核对 `.sha256` 文件。
2. 退出旧版，将 Lives 拖入“应用程序”文件夹。
3. 从“应用程序”打开 Lives，不要直接运行 DMG 内的副本；首次保存到“照片”时允许“仅添加照片”。

本版使用 Developer ID 签名，并完成 Apple 公证及票据钉入。本版通过正式版自动更新、官网和稳定下载镜像分发。

## 验证与已知限制

- 已验证反馈设备信息与本机真实数据一致（芯片、系统版本、设备型号、内存、显示器）、更新重启后的反馈提示、授权链路诊断日志与恢复兜底路径；自动化测试（Swift 全套与前端 58 项用例）通过，安装包签名、公证与 Gatekeeper 评估通过。
- 照片授权自动恢复依赖 macOS 对“仅添加照片”授权记录的重置行为，已在 macOS 27 开发预览版实测；若自动恢复未成功，导出界面会始终提供“复制修复命令”与“改存到文件夹”两条出路，不会无声卡死。
- 本次未重新完成 macOS 13/14、所有导出模板、iCloud 与 iPhone 的完整回归；相关素材集成测试缺少输入时明确跳过。
- 升级后建议先用非重要素材验证。反馈时附上系统版本、`~/Library/Logs/Lives/photo-reset.log` 日志和复现步骤，请勿公开私人照片、视频或未脱敏日志。
