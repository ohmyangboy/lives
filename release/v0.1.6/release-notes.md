# Lives 0.1.6 (Beta 测试版)

适用于 Apple Silicon Mac，要求 macOS 13 Ventura 或更高的正式版本。本版本专用于验证应用内自动更新与平滑重启升级机制。

## 更新要点

- **应用内自动检查与静默升级链路测试**：
  - 支持应用启动静默检测与后台流式下载；
  - 标题栏进度胶囊实时反馈下载与挂载进度；
  - 下载完成后一键重启，自动无缝切换并运行新版本。
- **Apple Developer ID 官方签名与 Apple 官方公证**：
  - 完整签署官方 Developer ID 证书并通过 Apple Notary 官方公证（Notarized & Stapled），在 macOS Gatekeeper 下免拦截顺畅运行。
