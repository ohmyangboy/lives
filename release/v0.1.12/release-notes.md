# Lives 0.1.12

正式版，适用于 Apple Silicon Mac，最低系统要求为 macOS 13。

## 本次更新
- 更新检查优先使用 Lives 自有更新源（download.1leaf.cc），GitHub 作为备用；限流、超时和无效清单不会误报“已是最新版”。
- 下载完成后强制校验文件大小、SHA-256、Bundle ID、版本、arm64 架构及 Developer ID 签名，校验失败不会替换当前应用。
- 更新下载支持取消、停滞保护和切源重试，保留更新完成后的重启与反馈入口。
- 延续 0.1.11 的真实设备诊断信息、更新重启反馈提示及照片权限恢复链路。

## 安装

1. 下载本页的 `Lives_0.1.12_aarch64.dmg`，核对 `.sha256` 文件。
2. 退出旧版，将 Lives 拖入“应用程序”文件夹。
3. 从“应用程序”打开 Lives，不要直接运行 DMG 内的副本；首次保存到“照片”时允许“仅添加照片”。

本版使用 Developer ID 签名，已完成 Apple 公证并封装票据；本版用于自有源更新链路验证。

## 验证与已知限制

- 已验证更新源优先级、限流回退、下载取消、大小与 SHA-256 校验、安装身份检查；自动化测试与生产构建通过。公证与真机升级闭环将在发布验收阶段记录。
- 照片授权自动恢复依赖 macOS 对“仅添加照片”授权记录的重置行为，已在 macOS 27 开发预览版实测；若自动恢复未成功，导出界面会始终提供“复制修复命令”与“改存到文件夹”两条出路，不会无声卡死。
- 本次未重新完成 macOS 13/14、所有导出模板、iCloud 与 iPhone 的完整回归；相关素材集成测试缺少输入时明确跳过。
- 升级后建议先用非重要素材验证。反馈时附上系统版本、`~/Library/Logs/Lives/photo-reset.log` 日志和复现步骤，请勿公开私人照片、视频或未脱敏日志。
