# Lives MVP PRD

**版本**：0.1.13  
**更新时间**：2026-07-21  
**状态**：MVP 内部测试

## 1. 产品定义

Lives 是一款 macOS 本地工具：用户从多个视频素材中挑选不同的 3 秒瞬间，放入拼贴画面格，生成一张可保存到 Apple“照片”的 Live Photo，或导出为可归档的 JPG + MOV 配对文件。

核心承诺：

- 全程在本机处理；不上传、复制或修改原视频。
- 同一素材可以重复放入多个画面格，并为每个格子设置独立的 3 秒选段、构图和缩放。
- 用户先从 DMG 安装；未来官网分发与应用内更新不属于当前 MVP 交付。

## 2. 目标用户与场景

| 用户 | 要完成的事 | 成功标准 |
| --- | --- | --- |
| 日常创作者 | 用聚餐、旅行、宠物等视频做一张可动拼贴 | 在 1–3 分钟内得到可播放的 Live Photo |
| 内容发布者 | 从大量素材中选取多个瞬间，做竖屏或横屏封面/素材 | 能按文件夹管理素材，重复使用同一视频的不同片段 |
| iPhone 用户 | 在 Mac 生成后同步到 iPhone 使用 | 保存到“照片”后经 iCloud 保持 Live 属性 |

## 3. 当前用户流程

1. 导入多个 MOV、MP4 或 M4V 视频，或导入一个文件夹。
2. 在“已导入”或文件夹项目 Tab 中浏览素材；素材只保存文件引用。
3. 选择画布方向与场景比例，再选择拼贴模板。
4. 从素材库拖动素材到各个画面格；同一视频可用于多个格。
5. 选中画面格后，在时间线选择该格的连续 3 秒；在画布中拖动画面、缩放并设置 Live 关键帧。
6. 选择静音、指定原声或混合原声；点击“生成 Live Photo”。
7. 在导出弹窗选择 1080P/720P 与保存到“照片”或指定文件夹；任务完成后查看结果。
8. 点击“清除拼贴”开始下一张作品：只清空当前拼贴配置，不清空素材库、项目 Tab、模板或画布偏好。

## 4. 已确认产品规则

### 素材与项目

- 支持直接导入多个文件；直接导入进入默认的“已导入”项目。
- 支持导入文件夹；文件夹内符合格式的视频会进入以文件夹命名的项目 Tab。
- 关闭项目 Tab 会移除该项目独占的素材引用；仍被其他项目引用的素材保留。
- 单个素材需至少 3 秒；支持格式为 MOV、MP4、M4V。
- 素材封面在可见区域惰性生成；封面解码限制为 2 路并发并使用最多 96 项的内存 LRU 缓存。该性能实现已完成，仍需大文件夹真机验收。

### 拼贴与编辑

- 支持 8 个模板：单画面、上下二拼、左右二拼、经典三拼、垂直三拼、左大右双、上大下双、大中小三拼。
- 支持比例：9:16、3:4、1:1、4:3、16:9；画布支持横/竖屏切换，切换时保留同方向的对应比例。
- 每个画面格独立保存素材、3 秒起点、裁剪中心和 1–3 倍缩放。
- 关键帧以 0.1 秒步进，范围 0.0–2.9 秒；预览播放 3 秒后停在关键帧。关键帧标签仅在拖动把手时显示。
- 画布空白区域点击后取消选中；选中画面格右上角可清空该格。

### 预览、声音与输出

- 预览支持静音、指定某个画面格原声、混合原声；导出 MOV 按此策略写入音频轨道。
- 导出质量由实际参与拼贴的素材决定：默认选可用最高质量；当前提供 1080P 与 720P，低于门槛时禁用 1080P。
- 导出到“照片”会请求仅添加照片的权限，并写入 JPEG + 配对 MOV；导出到文件夹会生成同名 JPG + MOV，自动避免覆盖。
- 输出始终为 3 秒、30fps、H.264 MOV + JPEG Live Photo 配对；封面使用用户设定关键帧。

## 5. MVP 范围边界

| 当前包含 | 当前不包含 |
| --- | --- |
| 本地素材管理、拼贴、裁剪、关键帧、声音、Live Photo 导出 | 云端素材库、账号体系、跨设备项目同步 |
| 保存“照片”或指定文件夹 | AirDrop 直传（已移除） |
| Apple Silicon DMG 内部测试 | App Store 上架、Intel/Universal 包、正式自动更新 |
| 文件夹项目与多素材浏览 | 非破坏性项目文件保存、编辑历史、批量导出 |

| 优先级 | 决策项 | 当前建议 |
