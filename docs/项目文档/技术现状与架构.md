# Lives 技术现状与架构

**基线版本**：0.1.0
**用途**：供后续 Agent 快速建立正确上下文，避免破坏本地隐私、Live Photo 配对和 macOS 授权链路。

## 1. 架构概览

```text
React / TypeScript UI
  ├─ 素材项目、拼贴配置、预览与导出弹窗
  ├─ Tauri Dialog / DragDrop / Shell bridge
  └─ src/nativeBridge.ts JSON 请求
             │
Tauri 主应用（macOS）
             │ sidecar stdin/stdout
Swift LivePhotoService
  ├─ MediaInspector：时长、尺寸、编码检测
  ├─ MediaLibraryScanner：文件夹视频扫描
  ├─ VideoRenderer：AVFoundation 合成、裁剪、H.264/AAC 输出
  ├─ LivePhotoPipeline：JPEG/MOV 配对、metadata、校验、临时目录
  └─ PhotoLibraryWorker：独立 LSUIElement helper 请求仅添加照片并保存
```

## 2. 关键数据模型与不变量

- `VideoClip` 是素材库中的原文件引用；`sourcePath` 指向用户文件，应用不复制原视频。
- `SlotClip` 是放入画面格后的独立实例；它有自己的 `id`、3 秒起点和裁剪参数，且通过 `sourceClipId` 追溯素材。
- 当前拼贴状态仅存在前端内存；素材项目和文件引用使用 localStorage 恢复。尚无可保存/重开的项目文件格式。
- 渲染项目固定 3 秒、30fps；画布支持 9:16、3:4、1:1、4:3、16:9 和 1080P/720P 输出矩阵。
- 每个拼贴画格的 Live 关键帧范围是 0–2900ms，按 100ms 量化；预览停帧和 JPEG 封面按画格分别取帧，MOV 仍使用统一的 still-image-time 元数据标记。
- 导出前必须填满当前模板全部画面格；不允许按素材库顺序自动补格。

## 3. 平台与权限约束

- 自 `0.1.8` 起，主应用与照片 helper 的签名必须包含 `com.apple.security.personal-information.photos-library`。它是 Hardened Runtime 的资源声明，不替代用户授权；PhotoKit 仍只申请 `.addOnly`。
- helper 申请授权前检查实际签名，缺失时报告配置异常，不再引导用户前往没有条目的系统设置。打包使用 `scripts/verify-photo-permissions.py` 同时检查主包和 helper；动态库符号链接在签名前展开，避免 Tauri 复制资源破坏签名。

- “照片”保存使用独立的 `Lives` helper app，申请 `PHPhotoLibrary.requestAuthorization(for: .addOnly)`；用户授权范围是仅添加照片，不读取图库。
- 输出到“照片”依赖 JPEG 与配对 MOV 的 content identifier 和 still-image-time 元数据；不得用普通 JPG/MOV 或 AirDrop 代替并宣称其为可靠 Live Photo 传输。
- helper 使用 `LSUIElement`，正常情况下不应在 Dock 额外显示；主 app 与 helper 的 bundle identity 必须在签名发布时一并维护。
- 任务临时文件位于系统临时目录下的 `Lives` 目录；成功、失败和取消后应清理。文件夹导出是用户明确选择的持久化目标。
- 当前 `signingIdentity` 为 `"-"`（ad-hoc），只适合开发/内部测试。Developer ID、公证和应用内更新均未接入。

## 4. 已知风险与协作注意事项

| 风险 | 处理原则 |
| --- | --- |
| 大量视频封面 | 保持 IntersectionObserver、2 路解码上限、任务取消和 LRU 缓存；不要一次创建所有 video/canvas |
| 拖拽冲突 | 区分 Finder 文件拖放与素材库内部拖放；内部拖拽不应触发全屏导入遮罩 |
| 关键帧交互 | 仅关键帧把手热区可指针拖动；轨道本身不能篡改关键帧；隐藏 range 仅负责键盘无障碍操作 |
| 模板改动 | 同时更新 `src/domain.ts` 和 Swift `TemplateLayout` / `LivePhotoPipeline.expectedClipCount`，并补测试 |
| 输出比例 | 前端画布比例与 Swift `supportsCanvas` 白名单必须同步；任何新尺寸需先验证 PhotoKit 配对 |
| 真实 Live 验收 | 浏览器/单元测试不能证明 iPhone 或第三方 App 支持，必须记录真机结果 |
