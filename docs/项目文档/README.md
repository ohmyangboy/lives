## 当前快照

- 产品：Lives，macOS 本地 Live Photo 拼贴工具。
- 当前正式版：`0.1.11`（2026-08-30）。
- 交付形态：Apple Silicon DMG；首次安装需拖入“应用程序”。
- 发布状态：已配置 Developer ID 签名、公证与稳定版自动更新；正式版通过稳定下载与自动更新渠道分发。最新证据见 [0.1.11 验证记录](../../release/v0.1.11/verification.md)。
- 旧验收记录：保留在 [../真机验收记录.md](../真机验收记录.md)，其中的 LiveCollage 名称和 `0.1.0` 环境字段仅代表历史记录；新的验收以本目录开发计划为准。

## 协作规则

1. 修改产品行为前，先更新 PRD 中对应的“已确认规则”或“待决策项”。
2. 每完成一个里程碑，更新开发计划的状态和验收证据；“已实现”不等于“已通过真机验收”。
3. 不要把 AirDrop 作为功能重新引入；该方案已验证不能可靠保留 Live Photo 配对关系，已明确移除。
4. 素材始终引用用户原文件，不复制上传；任何改变此隐私模型的需求必须先作为产品决策讨论。
