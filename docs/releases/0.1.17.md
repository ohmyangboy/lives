# Lives 0.1.17

发布日期：2026-10-28

加入 Live Photo 文件/照片库导入、统一「添加素材」配对，以及自定义比例下的原始画幅。

- 「添加素材」可一次混选视频与 Live Photo 原始照片/配对 MOV，按 ContentIdentifier 配对导入并保留原始尺寸与标识。
- 新增「从照片添加」：独立 Photos Helper 请求读取授权后通过系统选择器导入 Live Photo（每次最多 10 项）。
- 自定义比例可取当前选中画格/素材的原始画幅；行内重置恢复同一目标，编码范围仍为 1:3–3:1。
- Live 素材运动资源最短 1 秒；普通视频仍至少 2.5 秒。
- 同步 Helper / 主 App 照片用途说明，以及本地官网权限与隐私文案（未部署官网）。

本版不包含封面替换（cover replacement）能力。

支持 Apple Silicon，最低 macOS 13。下载与 SHA-256 见 [GitHub Release](https://github.com/ohmyangboy/lives/releases/tag/v0.1.17)。

---

Adds Live Photo file/Photos library import, unified Add Media pairing, and native aspect ratio for custom crops.

- Add Media accepts mixed video and Live Photo still/MOV selections, pairs by ContentIdentifier, and keeps original dimensions and identifiers.
- Adds From Photos: a dedicated Photos Helper requests read access and imports Live Photos via the system picker (up to 10 items).
- Custom ratio can follow the selected cell/source native aspect; inline Reset restores the same target within the existing 1:3–3:1 encode bounds.
- Live motion assets allow a 1-second minimum; ordinary videos remain at least 2.5 seconds.
- Updates Helper/main app photo usage strings and local website permission/privacy copy (website not deployed in this bump).

Cover replacement is not included in this release.

Requires Apple Silicon and macOS 13 or later. Downloads and SHA-256 checksums will be on the [GitHub Release](https://github.com/ohmyangboy/lives/releases/tag/v0.1.17).
