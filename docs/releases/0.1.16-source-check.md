# 0.1.16 发布来源与验证范围

日期：2026-10-06

本次按用户明确要求，将当前 Lives Mac 工作区全部 46 个未提交文件纳入发布副本，包括胶卷与观片器模型、关键帧控制、时长调节、预览播放和原生导出补帧，以及图标和 Lives Mobile 入口。快照取自工作区提交 `812f8e0bd0332d0b2165775e5dba3e9d64be77b9`，逐文件 SHA-256 核对无遗漏；原始工作区未被覆盖。版本统一为 0.1.16。

- 项目源码沿用本仓库 GPL-3.0-only 授权；用户已明确要求发布当前全部修改。图标与二维码来源见 [0.1.15 来源核对](0.1.15-source-check.md)。

- 保留 macOS 27 上 Rust 构建期依赖不剥离符号的修复。新增 Node 20.19.9 类型声明与 TypeScript 配置，修复模型测试导致的生产构建错误；未升级运行时依赖。

- 前端：9 个测试文件、104 项测试通过；TypeScript 与生产构建通过。
- LivesCore：92 项测试，7 项因缺少外部素材跳过，0 失败。

- 界面：合成 5 秒视频导入与画格拖放；胶卷和观片器模型均 ready；时间线下限 1 秒、上限 15 秒、0.1 秒步进及关键帧钳制通过。15 秒输出显示末帧补齐 10 秒。
