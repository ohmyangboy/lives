# Lives 0.1.21

发布日期：2026-11-03

素材排序更顺手，画布展示更清爽。

- 素材区新增排序菜单，支持导入时间、创建时间、名称和时长，默认最近导入优先，可切换升序或降序。
- Live 标识和画格操作移到画布外，去掉重复提示，将更多空间留给预览内容。
- 时间线时长使用白字，选区增加圆角；快捷时长入口简化为「时长」。
- 最小窗口下比例选项保持单行，保留自定义宽高输入布局。
- 保留上一版已发布的照片诊断、复制日志、导入进度和紧凑界面改进。

---

Makes media sorting easier and keeps the preview canvas clear.

- Adds sorting by import time, creation time, filename, or duration, with newest imports first by default and ascending or descending order.
- Moves the Live indicator and slot actions outside the canvas and removes repeated hints to give the preview more room.
- Uses white duration text and rounded timeline selections, with a shorter duration control label.
- Keeps aspect-ratio options on one line at the minimum window size while preserving custom size inputs.
- Retains the previous release's Photos diagnostics, Copy Logs, import progress, and compact interface improvements.
