# Lives 0.1.15 发布来源核对

日期：2026-10-06。

## 范围与依据

- 本次发行以 `812f8e0` 的 Lives Mac 源码为基础，仅加入本次图标与 Lives Mobile 反馈入口，以及发布所需的版本、说明和部署配置；工作区内其他未提交功能未纳入。
- 仓库可见提交的作者为 `ohmyangboy <ohmyangboy@gmail.com>`，未发现其他贡献者的提交。`THIRD_PARTY_NOTICES.md` 记录 Swift 与 LivesCore 为自研实现；第三方组件按原许可保留。
- 项目自有源码继续按已公开的 GPL-3.0-only 分发，不撤回历史版本的授权，也不改变品牌标识的使用政策。
- Mac 与 Mobile 图标取自本仓库官网资源。二维码由用户提供，内容为 `https://apps.apple.com/app/id6807655743`；用户明确要求用于 Lives Mac，并授权本次官方 Release。
- `WatermarkAppIcon.png` 为现有 Lives 品牌图形（Git blob `0c7bc7309da3b7561741a27d9ec902609dd79d7c`），本次未修改，随用户授权的官方 Lives 构建继续分发；运行时资源仍保留。

以上记录列出本次发行采用的来源与授权依据，不向第三方授予额外的品牌权利。

## 固定来源与第三方资料

正式构建由干净提交及 `mac/v0.1.15` 固定。App commit、Core tree、四个附件 SHA-256 由 `build-receipt.json` 与冻结 publication manifest 记录。

正式发布入口强制生成和检查 Rust / npm 生产依赖许可报告，随 App 分发；MPL 与 FFmpeg 对应源码附件由锁文件与源包校验和生成，沿用既有附件白名单。
