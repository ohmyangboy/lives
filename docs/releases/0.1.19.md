# Lives 0.1.19

发布日期：2026-11-03

补齐照片保存诊断与复制日志，修复反馈面板溢出。

- 反馈面板右上角新增小号「复制日志」按钮，复制设备信息及最近照片保存诊断，并显示复制结果。
- 照片授权与保存记录有界诊断，支持失败后重新打开应用再反馈；不记录素材内容、文件名、路径或照片标识。
- 邮件和 GitHub Issue 草稿包含同一份诊断摘要，可在发送前查看或删除，不会自动发送。
- 修复反馈面板文字和二维码卡片的横向溢出，较矮窗口可在面板内滚动。
- 补齐素材扫描、读取、照片选择与导入进度反馈，保留照片导入取消操作。

Adds missing Photos diagnostics and Copy Logs, and fixes feedback panel overflow.

- Adds a compact Copy Logs button in the feedback header, with device information, recent Photos diagnostics, and copy status.
- Keeps bounded diagnostics for Photos authorization and saves across relaunches, without media contents, filenames, paths, or photo identifiers.
- Email and GitHub Issue drafts include the same diagnostic summary for review or removal before sending; nothing is sent automatically.
- Fixes horizontal text and QR-card overflow and supports scrolling within the feedback panel on shorter windows.
- Improves progress feedback for scanning, reading, Photos selection, and import, while retaining Photos import cancellation.
