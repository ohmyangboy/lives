本次更新

  • 修复保存到“照片”时提示前往系统设置、却没有 Lives 条目的问题：补齐主程序和照片辅助程序的签名权限。

  • 安装窗口调整为 640 × 440，加入拖拽箭头与“安装后从应用程序打开”的提示。
  • 增加实际签名检查，修复辅助程序动态库复制导致的签名封装问题。
  • 修正 beta 版本比较，预发布版可以识别对应正式版更新。
  • 多画格拼贴可分别设置每一格的 Live 关键帧，调整一格不会联动其他画格，导出封面也会保留各自设定。
  • 修复生成的封面照片方向错误，保持与预览和视频画面一致。

安装与渠道

下载正式版 DMG · 发布说明与 SHA-256

退出旧版，将 Lives 拖入“应用程序”，再从“应用程序”打开。不要直接运行 DMG 内的副本；选择“保存到照片”时按系统提示授权。安装包已使用 Developer ID 签名并完成 Apple 公证。

正式版可手动安装，也可通过应用内自动更新升级。无需重置其他应用的照片权限。

验证范围

已验证照片授权弹窗与授权记录、签名权限、安装镜像布局和完整性，并运行自动化测试。测试机为 macOS 27 开发预览版；本次未重新完成 macOS 13/14、全部导出模板、iCloud 与 iPhone 的完整回归。请先使用非重要素材测试。
