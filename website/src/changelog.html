更新日志

v__LIVES_VERSION__

2026 年 10 月 28 日 · 正式版 · Apple Silicon / macOS 13+

本次更新

  • 「添加素材」支持混选视频与 Live Photo 原始照片/配对 MOV，按 ContentIdentifier 配对导入。
  • 新增「从照片添加」，通过系统选择器导入 Live Photo（每次最多 10 项）。
  • 自定义比例可跟随选中画格/素材的原始画幅，并支持行内重置。
  • 可为画格选择自定义封面图片，导出时用作 Live Photo 封面；也可清除后回到时间线选帧。
  • Live 素材运动资源最短 1 秒；普通视频仍至少 2.5 秒。
  • 同步照片权限与隐私说明文案。

安装与渠道

下载正式版 DMG · 发布说明与 SHA-256

退出旧版，将 Lives 拖入“应用程序”，再从“应用程序”打开。不要直接运行 DMG 内的副本；选择“保存到照片”时按系统提示授权。安装包已使用 Developer ID 签名并完成 Apple 公证。

正式版可手动安装，也可通过应用内自动更新升级。若此前误点过“不允许”，升级后可直接在导出界面点击“重新授权并保存”恢复。

验证范围

本版验证 Live 导入、照片库选择器、原始比例与封面替换，并运行前端和 Swift 原生自动测试。正式安装包使用 Developer ID 签名并完成 Apple 公证。完整的照片授权、HDR 导出、iCloud 与 iPhone 同步及旧版自动更新仍需设备验收。

遇到问题请通过 GitHub Issues反馈，勿上传私人照片、原视频或未脱敏日志。
