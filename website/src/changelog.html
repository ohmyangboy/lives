更新日志

v__LIVES_VERSION__

2026 年 11 月 3 日 · 正式版 · Apple Silicon / macOS 13+

本次更新

  • 反馈面板右上角新增小号「复制日志」，便于复制设备信息与最近照片保存诊断。
  • 照片授权与保存诊断可跨重启保留，不记录素材内容、文件名、路径或照片标识。
  • 反馈草稿附带有界诊断摘要，可在发送前查看或删除，不会自动发送。
  • 修复反馈面板文字与二维码卡片横向溢出，较矮窗口支持内部滚动。
  • 完善素材扫描、读取、照片选择和导入阶段的进度反馈。

安装与渠道

下载正式版 DMG · 发布说明与 SHA-256

退出旧版，将 Lives 拖入“应用程序”，再从“应用程序”打开。不要直接运行 DMG 内的副本；选择“保存到照片”时按系统提示授权。安装包已使用 Developer ID 签名并完成 Apple 公证。

正式版可手动安装，也可通过应用内自动更新升级。若此前误点过“不允许”，升级后可直接在导出界面点击“重新授权并保存”恢复。

验证范围

本版检查反馈布局、日志复制与脱敏边界，并运行前端及 Swift 原生自动测试。正式安装包使用 Developer ID 签名并完成 Apple 公证。完整的照片授权、HDR 导出、iCloud 与 iPhone 同步及旧版自动更新仍需设备验收。

遇到问题请通过 GitHub Issues反馈，勿上传私人照片、原视频或未脱敏日志。
