本次更新

  • 反馈与“关于”中的设备信息改为真实系统数据：不再显示 WebView 内置的占位信息（“MacIntel”、Intel Mac 的 User Agent），改为采集真实的操作系统版本、芯片型号、设备型号、内存与主显示器信息。
  • 应用内更新并重启后，首次启动会弹出“已更新”提示：遇到问题或有功能建议可一键打开预填好的反馈邮件联系开发者，每次更新只提示一次。
  • 照片权限恢复链路收尾：授权状态由全新辅助进程读取，重置动作串行化并支持取消；自动化恢复失败时始终提供“复制修复命令”与“改存到文件夹”两条出路。
  • 包含 0.1.10 的照片权限拒绝后应用内恢复、画布自定义比例拖拽与文件夹素材库同步。

安装与渠道

下载正式版 DMG · 发布说明与 SHA-256

退出旧版，将 Lives 拖入“应用程序”，再从“应用程序”打开。不要直接运行 DMG 内的副本；选择“保存到照片”时按系统提示授权。安装包已使用 Developer ID 签名并完成 Apple 公证。

正式版可手动安装，也可通过应用内自动更新升级。若此前误点过“不允许”，升级后可直接在导出界面点击“重新授权并保存”恢复。

验证范围
