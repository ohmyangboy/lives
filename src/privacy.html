隐私说明 · v__LIVES_VERSION__

本地处理，是 Lives 的边界。

生效日期：2026 年 7 月 22 日。本说明适用于 Lives v__LIVES_VERSION__ 独立分发预览版、产品网站以及你主动发起的支持沟通。

  • APP素材只在本机处理
  • WEBSITE不部署独立分析或广告
  • CONTROL权限和反馈由你主动发起

App 如何处理素材

  • Lives 在你的 Mac 本地处理视频、缩略图、拼贴配置和生成结果。
  • 素材库使用原文件引用；Lives 不上传或修改原视频。
  • 导出到文件夹时，只向你主动选择的位置写入 JPG 与 MOV 配对文件。
  • 生成过程所需的临时文件会在成功、失败或取消后清理。

照片权限

只有当你选择“保存到照片”时，Lives 才会请求 macOS 的“仅添加照片”权限，用于写入生成的 Live Photo。Lives 不读取、浏览或上传现有照片。授权会持续有效，直到你在“系统设置 → 隐私与安全性 → 照片”中更改。

App 不收集什么

v__LIVES_VERSION__ 不提供账号、广告、云端素材库、行为分析或应用内自动更新，也不会自动上传崩溃日志。Lives 运营者不会从 App 接收你的素材、编辑操作、设备标识或使用记录。若未来增加更新检查、诊断、分析、云同步或支付功能，将在启用前更新本说明并提供必要提示。

网站与 GitHub 托管

Lives 官网不部署自行控制的 Cookie、广告、像素或独立分析脚本。网站、公开反馈和安装包分别由 GitHub Pages、GitHub Issues 与 GitHub Releases 托管；当你访问这些服务时，GitHub 可能处理 IP 地址、设备与浏览器信息、访问时间、页面互动、下载或安全日志。相关数据由 GitHub 按其规则处理，详见 GitHub General Privacy Statement。

反馈邮件与公开 Issue

你可以选择不提交任何反馈。GitHub Issues 是公开空间，请勿上传私人影像、个人信息或未经脱敏的日志。发送至 ohmyangboy@gmail.com 的邮件会由 Gmail 承载，Google 可能处理邮件内容、发件地址、时间和技术元数据，详见 Google 隐私权政策。运营者只将你主动提供的信息用于回复、排查和改进 Lives。

保存、更正与删除

App 没有 Lives 运营者控制的云端账户或远程素材库，因此没有可供运营者查询或删除的 App 端个人数据。对于运营者控制的支持邮件，你可以通过同一邮箱请求更正或删除；对于 GitHub 或 Google 控制的数据，请使用相应平台提供的账户与隐私工具。为处理安全事件、争议或履行适用法律要求，必要记录可能在合理范围内保留。

运营者、联系与变更
