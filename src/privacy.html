隐私说明 · 0.1.0

本地处理，是 Lives 的边界。

生效日期：2026 年 7 月 21 日。本说明适用于 Lives 0.1.0 独立分发预览版及其产品网站。

App 如何处理素材

  • Lives 在你的 Mac 本地处理视频、缩略图、拼贴配置和生成结果。
  • 素材库保存的是原文件引用；Lives 不会上传、复制或修改原视频。
  • 导出到文件夹时，只写入你主动选择的位置。
  • 生成过程中使用的临时文件会在成功、失败或取消后清理。

照片权限

只有当你选择“保存到照片”时，Lives 才会请求 macOS 的“仅添加照片”权限，用于写入生成的 Live Photo。Lives 不读取、浏览或上传现有照片。授权会持续有效，直到你在“系统设置 → 隐私与安全性 → 照片”中更改。

账号、分析与崩溃日志

0.1.0 不提供账号、广告、云端素材库或行为分析，也不会自动上传崩溃日志。如果未来增加更新检查、诊断或分析功能，本页面会在功能启用前更新。

网站与下载服务

产品网站和安装包由 GitHub Pages 与 GitHub Releases 托管。GitHub 可能基于安全和运行维护需要处理 IP 地址、访问时间、浏览器信息和下载日志；Lives 不使用这些数据制作广告画像。详情请参阅 GitHub 隐私声明。

运营者、联系与变更

Lives 的运营者为 ohmyangboy。隐私、安全或需要包含非公开信息的问题，请发送邮件至 ohmyangboy@gmail.com；一般问题也可通过 GitHub Issues 反馈，但请勿公开私人影像、个人信息或未经脱敏的日志。隐私说明发生重要变化时，将在版本发布页记录生效日期和变更内容。
